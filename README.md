# Legacy Pixels Studio Website

Clean static website package.

Pages:
- index.html
- services.html
- about.html
- contact.html
- book-now.html

The site uses the supplied Legacy Pixels branding and Goodmov-style layout/animations. Vendor assets under `wp-content` are retained only where required by the exported static pages. WordPress scrape artifacts, duplicate pages, feeds, XML-RPC, REST/oEmbed files, and template-kit export files have been removed.
